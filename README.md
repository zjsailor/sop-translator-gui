# SOP Translator GUI

桌面版 SOP 保留格式翻译工具（Windows EXE）。

## 功能
- 自定义 `base_url`
- 自定义模型名
- 输入 `sk-` 开头 API Key
- 选择输入文件（`.docx` / `.xlsx`）
- 自定义输出目录（默认桌面）
- 一键翻译并保留原文档结构与格式

## 使用方式
1. 打开 `SOPTranslator.exe`
2. 填写 `base_url`、`model`、`API Key`
3. 选择输入文件与输出目录
4. 点击“转换”

## 安全说明
- 本项目不包含任何硬编码 API Key。
- API Key 仅在本地运行时输入并用于当前请求。
